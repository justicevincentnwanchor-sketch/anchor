# Zuros Browser

A clean, browser-inspired start page for searching, saving a note, and returning to useful places.

## Preview

Open `index.html` directly or run `python3 -m http.server 4173` and visit `http://localhost:4173`.

## Google Search

The site includes crawlable metadata, structured data, `robots.txt`, and a sitemap. To verify ownership in Google Search Console, add the verification token Google provides to the `<head>` of `index.html`, then submit the deployed URL and sitemap.
